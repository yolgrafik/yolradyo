# RadyoYol Project Rules

## Genel Kurallar
- Bu proje Laravel tabanlı bir radyo web sitesidir.
- Mevcut tasarım düzeni bozulmamalıdır.
- Kod değişiklikleri mümkün olduğunca mevcut yapıyı koruyarak yapılmalıdır.

## Tasarım
- Sol içerik ve sağ sidebar hizaları eşit olmalıdır.
- Kart yapıları aynı padding ve margin kullanmalıdır.
- Responsive yapı korunmalıdır.

## Kodlama
- Laravel blade yapısı kullanılmalıdır.
- CSS düzeni mevcut dosyalarda yapılmalıdır.
- Gereksiz yeni dosya oluşturulmamalıdır.

## Amaç
Modern, hızlı ve stabil bir radyo web sitesi.
