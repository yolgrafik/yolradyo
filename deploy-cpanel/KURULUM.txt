CPANEL KURULUM ADIMLARI
=======================

1. FTP ile bu klasörün İÇERİĞİNİ public_html'e yükleyin.
   (index.php, .htaccess, assets, build, uploads, yolcu klasörü hepsi public_html'de olmalı)

2. cPanel > Terminal veya SSH ile:
   cd ~/public_html/yolcu
   cp .env.example .env
   php artisan key:generate

3. .env dosyasını düzenleyin (File Manager veya nano):
   - APP_URL=https://siteniz.com
   - APP_ENV=production
   - APP_DEBUG=false
   - DB_* veritabanı bilgileri

4. Devam:
   php artisan storage:link
   php artisan migrate --force
   chmod -R 775 storage bootstrap/cache

5. Tarayıcıda sitenizi açın.
